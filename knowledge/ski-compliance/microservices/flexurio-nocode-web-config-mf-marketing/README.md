# Flexurio No-code Web Configuration — MF Marketing

Prebuilt Flutter web application and editable no-code page configuration for marketing, incentives, budgets, projects and reporting. This checkout contains compiled web assets rather than the Flutter application source.

## Architecture and files

| Path | Purpose |
| --- | --- |
| [index.html](index.html) | Web entry document |
| [main.dart.js](main.dart.js) | Compiled Flutter application |
| [flutter_bootstrap.js](flutter_bootstrap.js) | Flutter loader bootstrap |
| [flutter_service_worker.js](flutter_service_worker.js) | Generated service worker/cache code |
| [assets/asset/configuration/configuration.json](assets/asset/configuration/configuration.json) | Application identity, backend/auth URLs, entity registration and theme |
| [assets/asset/configuration/entity/](assets/asset/configuration/entity/) | Entity views and request/action templates |
| [assets/asset/configuration/landing_page.json](assets/asset/configuration/landing_page.json) | Landing-page content and theme |
| [version.json](version.json) | Packaged version metadata |

This static web checkout does not register backend HTTP handlers. The API table documents outgoing request templates, including query strings and placeholders, rather than server endpoints owned by this repository. It contains no pubspec.yaml/Dart source build setup.

## Local preview and configuration

Review `backend_host`, `auth_url` and per-action absolute URLs before opening the UI. A local static preview can still issue requests to the configured backend; it does not create an isolated backend.

```sh
python3 -m http.server 8081 --bind 127.0.0.1
```

Open the local server after configuring approved development targets. This preview command was not executed during the README refresh. Authentication and mutations are handled by the configured backend. Changing `backend_host` does not rewrite hardcoded absolute URLs.

## Complete configured API reference

All **144 URL-bearing request objects** found recursively in `assets/asset/configuration/**/*.json` are listed below. Repeated URLs are retained because they belong to different actions. Placeholders such as `{backend_host}`, `{id}` and `{page.period}` are evaluated by the runtime. A missing method is reported rather than guessed. Additional calls embedded/generated by the compiled runtime cannot be proven from editable JSON alone.
